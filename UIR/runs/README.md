## Основные результаты

### Умеренное преобразование

- `ROI 250`:
  число совпадений уменьшается от `1549` при `variance = 5` до `975` при `variance = 300`
- `ROI 250`:
  `matrix_frobenius_error` меняется в диапазоне от `0.12398` до `0.26416`
- `ROI 500`:
  число совпадений уменьшается от `11743` при `variance = 5` до `8033` при `variance = 300`
- `ROI 500`:
  `matrix_frobenius_error` меняется в диапазоне от `0.03443` до `0.13156`

Вывод:
- Полный объем `ROI 500` дает существенно больше совпадений и меньшую ошибку, чем `ROI 250`.
- Даже при `variance = 300` регистрация остается устойчивой.

Показательный пример:
- [`roi500_var0300/plots/summary.json`](./centered_affine_rz12_rym6_rx4_sx1p06_sy0p95_sz1p03_shxy0p0025_shyzm0p0015_tx8_tym6_tz5/roi500_var0300/plots/summary.json)
- `match_count = 8033`
- `matrix_frobenius_error = 0.13156`
- `translation_l2_error = 0.13156`

### Жесткое преобразование

- `ROI 250`:
  число совпадений находится в диапазоне `40-58`
- `ROI 250`:
  `matrix_frobenius_error` меняется от `0.36924` до `1.88475`
- `ROI 500`:
  число совпадений находится в диапазоне `338-399`
- `ROI 500`:
  `matrix_frobenius_error` меняется от `0.32211` до `0.59855`

Вывод:
- Для жесткого преобразования `ROI 250` является неустойчивым режимом.
- Переход к `ROI 500` заметно улучшает результат, но задача остается сложной.

Показательный пример:
- [`roi500_var0040/plots/summary.json`](./centered_affine_rz68_rym22_rx19_sx1p5_sy0p88_sz1p33_shxy0p01_shyzm0p01_tx12_tym9_tz7/roi500_var0040/plots/summary.json)
- `match_count = 388`
- `matrix_frobenius_error = 0.35300`
- `translation_l2_error = 0.35300`

## Общий вывод

- На текущих данных наиболее устойчивый режим: умеренное преобразование с `ROI 500`.
- Для этого режима метод сохраняет работоспособность во всем проверенном диапазоне шумов, включая `variance = 300`.
- Жесткое преобразование подходит как стресс-тест.
- Для жесткого преобразования использование полного объема обязательно: на `ROI 250` результат заметно хуже.
